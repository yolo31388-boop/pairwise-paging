实现一个虚拟内存分页模拟器（多级页表 + TLB + 可插拔置换策略
FIFO/LRU/Clock + 完整统计），只用 Python 标准库。

背景：paging.py 是骨架（PagingSimulator 类方法 raise
NotImplementedError），tests/test_paging.py 是验收测试。

需求（feature，仿操作系统虚拟内存核心语义）：
1. 地址拆分：virtual_bits 位虚拟地址；页大小 2**page_bits（默认
   64B）；页号按 levels 级均分（levels=2 时每级 5 位，levels=3
   时每级 6 位），页内偏移为最低 page_bits 位
2. 页表：按需建立"根 dict -> 逐级 dict -> {frame, dirty}"；
   表项缺失即缺页（frame_count 帧）
3. TLB（tlb_size 条，LRU 顺序）：vpn -> frame；命中直接返回物理
   地址；满时淘汰最久未用条目（evictions 计数，TLB 淘汰也算）
4. 置换策略 policy（'fifo' | 'lru' | 'clock'）：
   - fifo：按帧分配顺序（先进先出）选淘汰帧
   - lru：按最近访问时间（last_used 最小者）选淘汰帧，访问更新
   - clock：每帧维护引用位 ref；访问命中置 ref=True；淘汰时从
     时钟指针扫描：ref 为 True 的帧清为 False 并继续，遇第一个
     ref 为 False 的帧淘汰，指针停在下一帧
5. 缺页换帧：无空闲帧时按 policy 换帧；被置换页若 dirty 则写回
   主存（dirty_writebacks 计数），并从页表与 TLB 移除旧映射
6. 写访问置帧与页表表项 dirty；读访问不变
7. access(vaddr, write=False) -> int：返回物理地址
   （frame * page_size + offset）
8. stats() -> {accesses, tlb_hits, tlb_misses, page_faults,
   evictions, dirty_writebacks, hit_rate, page_table_walks}：
   hit_rate = tlb_hits/accesses，page_table_walks = tlb_misses

验收：
- python -m pytest tests/test_paging.py -q 全绿
- 覆盖：TLB 命中/每新页一次缺页/TLB LRU 淘汰（容量 2 连续挤 3
  页，4 次全 miss、淘汰 2 次、缺页仅 3 次）/物理地址偏移正确/
  帧 LRU 置换（最早页被逐出，重访重新缺页）/写脏页置换写回/
  干净页置换不写回/跨 L1 的二级页表/统计字段含 hit_rate 与
  page_table_walks/FIFO 策略可跑/Clock 策略可跑/三种策略参数
  切换一致性/24 位 3 级页表翻译/8 页 8 帧工作集驻留（第 2 轮起
  全 TLB 命中）

要求：
- 只 import 标准库；页表、TLB、三种置换算法必须真实实现
  （禁止直接线性映射所有地址；Clock 必须用引用位扫描，不能用
  FIFO 顶替）；别改测试
